# Contributing

Thanks for looking at the kit. A few rules keep the repository easy to maintain.

1. **Open an issue first.** Use the [Feedback or a problem form](https://github.com/Jakub-Owczarzak/ai-workspace-kit/issues/new/choose)
   to describe the problem or the idea. For a bug, include your AI tool and operating system, and what the installer
   printed.
2. **Then send a pull request from a fork**, and link the issue in it. Keep it small: one change, with a test where the
   change is code (`npm test` must pass).
3. **Pull requests that were not discussed in an issue, bulk changes, or changes generated by an agent without a person
   reading them will be closed** without review.

The kit has no skill that pushes to this repository or opens pull requests for you. To get a newer kit, run
`npx ai-workspace-kit@latest init --force` in your project (see
[docs/install-and-update.md](docs/install-and-update.md#9-keeping-the-kit-up-to-date)).
